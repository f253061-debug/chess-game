# ♟️ Chess Game

A two-player Chess game developed in **C++** using the **SFML** multimedia library and **Object-Oriented Programming (OOP)** concepts.

## 🎮 About the Project

This project is a graphical Chess game created as a C++ project. It uses SFML to provide the game's graphical interface and implements the core logic required for playing Chess.

## ✨ Features

* ♟️ Two-player Chess gameplay
* 🎨 Graphical interface using SFML
* 🧩 Chess board and pieces
* 🔄 Turn-based gameplay
* ♟️ Piece movement and game logic
* 🖱️ Mouse-based interaction
* 💻 Object-Oriented Programming concepts

## 🛠️ Technologies Used

* **C++**
* **SFML**
* **Object-Oriented Programming**
* **Visual Studio**

## 📂 Project Structure

The project contains the C++ source code, SFML resources, images/assets, and other files required to run the game.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in Visual Studio.
3. Make sure SFML is properly configured.
4. Build the project.
5. Run the Chess game.
